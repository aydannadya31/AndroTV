# MediaDash Hub — Web & APK Dağıtımı

Bu dizin, **MediaDash Hub** uygulamasının Android TV ve Android Telefon cihazlarına ayrılmış bağımsız APK paketlerini doğrudan web üzerinden indirmeyi sağlayan resmi GitHub Pages dağıtım sitesini içerir.

## Canlı Dağıtım Dosyaları

- `index.html`: Modern, responsive ve zümrüt yeşili temalı web indirme sayfası.
- `MediaDashHub-TV-v1.0.apk`: Android TV & TV Kutuları için özel Alıcı ve Akıllı Panel APK'sı (Bölünmüş Dashboard, 10-foot D-pad kumanda uyumu, dahili Eşleşme QR Kodu, 4K Oynatıcı).
- `MediaDashHub-Phone-v1.0.apk`: Android Akıllı Telefonlar için özel Medya İletici APK'sı (Kamera ile TV QR okuma, Galeri/Ses Seçici, Sıfır TV Depolaması ile Doğrudan RAM Akışı, Kilit Ekranı Koruması).
- `MediaDashHub-v1.0.apk`: Her iki cihazı otomatik algılayan Universal APK.
- `*.sha256`: İndirilen APK paketlerinin bütünlük ve güvenlik doğrulama özetleri.
